# Quando esploderà la bolla delle Big tech?

Dashboard di Info Data sui market mover delle Magnifiche 7 (Apple, Microsoft, Alphabet, Amazon, Meta, Nvidia, Tesla): variazioni di Borsa, calendario delle trimestrali, notizie che hanno alimentato il timore di una bolla dell'AI e catalizzatori della settimana.

Dati raccolti da fonti pubbliche al 14 ottobre 2026; ogni notizia riporta fonte e link. Non è una raccomandazione di investimento.

La pagina è un unico file HTML (`index.html`) con dati e grafici incorporati.
